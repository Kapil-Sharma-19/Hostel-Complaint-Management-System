# 🏢 Hostel Complaint Management System

A full-stack web application for managing hostel complaints, built using **React**, **Node.js**, **Express**, **JavaScript**, and **MySQL**.

---

## 🚀 Features

- ✅ User authentication and authorization
- ✅ Students can submit complaints easily
- ✅ Wardens/Admins can view, resolve, and close complaints
- ✅ Complaint status tracking
- ✅ Multiple hostel groups
- ✅ Admins can add/remove students
- ✅ Pre-defined student database with hostel info, room number, roll number, email, and phone
- ✅ Signup with college email & automatic hostel assignment

---

## 🗂️ Tech Stack

| Tech | Description |
|------|--------------|
| **Frontend** | React, JavaScript |
| **Backend** | Node.js, Express.js |
